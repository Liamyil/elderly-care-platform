## 一、微信订阅消息（免费，主力）

> ✅ 2026-10-10 已完成：AppID（wx10023d2b4307a19e）与 AppSecret 已配置进后端（application.yml 的 WECHAT_APPID/WECHAT_SECRET，可用环境变量覆盖）；project.config.json 的 appid 已同步更换为该小程序 ID。微信登录/绑定链路已可用，**剩余步骤仅为订阅消息模板申请**。

**在微信公众平台（mp.weixin.qq.com）完成：**

| 步骤 | 操作 |
|---|---|
| 1 | 小程序账号完成**微信认证**（未认证无法申请订阅消息） |
| 2 | 【功能 → 订阅消息】→ 公共模板库搜索并选用 3 个模板：① 服务指派提醒 ② 服务超时提醒 ③ 结算到账提醒（具体模板名以库里为准） |
| 3 | 申请模板时**字段建议**（尽量选含这些字段的模板）：thing1=服务类型、time2=时间、amount3=金额 |
| 4 | 记下 3 个模板ID |

**填入代码（两处）：**

1. `utils/subscribe.js` → `TEMPLATE_IDS` 三个值
2. 后端启动参数（或改 application.yml）：
   - `WECHAT_APPID`（小程序后台【开发管理→开发设置】）
   - `WECHAT_SECRET`（同上，注意保密）
   - `WECHAT_TPL_ASSIGN` / `WECHAT_TPL_TIMEOUT` / `WECHAT_TPL_SETTLE`（上一步的 3 个模板ID）
   - `WECHAT_MP_STATE`：开发阶段 `developer`，体验版 `trial`，正式上线 `formal`

> 如果申请到的模板字段和 thing1/time2/amount3 不一致，告诉我字段名，我调整发送代码（字段 key 必须与模板一致）。

## 二、短信（阿里云，关键节点兜底）

**在阿里云控制台完成：**

| 步骤 | 操作 |
|---|---|
| 1 | 开通【短信服务】（需企业实名认证） |
| 2 | 【国内消息】→ 申请**签名**（如"智慧互助养老"，需平台资质说明） |
| 3 | 申请 2 个**模板**：① 指派通知（如"您有新的社区指派订单：${type}，预约时间${time}"）② 超时提醒（如"您的订单${type}已超过预约时间，请尽快完成服务"） |
| 4 | 创建 **AccessKey**（右上角头像 → AccessKey 管理） |

**填入后端启动参数：**

- `SMS_AK` / `SMS_SK`（AccessKey ID/Secret）
- `SMS_SIGN`（签名名）
- `SMS_TPL_ASSIGN` / `SMS_TPL_TIMEOUT`（模板CODE，如 SMS_123456789）

> 若公司决定用腾讯云短信，告诉我，我替换短信服务实现（接口不变）。

## 三、配置后的验证方法

1. 小程序重新编译 → 用任意账号登录一次 → 后端日志出现「openid 绑定成功」= openid 链路 OK
2. 互助员接单时弹出"订阅消息授权"弹窗 → 点允许
3. H5 管理员登录后浏览器访问 `http://localhost:3000/api/admin/notify/test` → 管理员自己的微信收到测试订阅消息 = 推送链路 OK
4. 管理员指派一单给互助员 → 互助员微信收到订阅消息 + 手机收到短信 = 全链路 OK
