## 二、环境准备（演示前 5 分钟）

1. 双击 `启动服务.bat`：自动启动 MySQL、后端（端口3000）、微信开发者工具
2. 双击 `启动管理后台.bat`：自动用 Edge 打开 H5 后台（http://localhost:5173）
3. 微信开发者工具里打开项目根目录，**右上角「详情」→「本地设置」→ 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**（真机预览必须勾）
4. 手机与电脑连**同一个 WiFi**（真机演示需要）

## 四、演示剧本（走完整闭环，约 10 分钟）

**第 1 幕 · 老人下单（陈阿姨）**
1. 小程序登录陈阿姨 → 首页点「陪诊服务」入口
2. 服务选择页：左右分类浏览，有介绍和销量 → 点「上门接送」
3. 类型详情页：看参考价格、**健康评估问卷入口**、**用户评价区（2 条真实评价）**
4. 点「健康评估问卷」→ 填 6 题 → 提交 → 看风险分级结果（中/高风险会有建议提示）
5. 点「立即下单」→ 发布页（陪诊服务类型已锁定，**健康评估块显示评估结果**）→ 填时间/地址 → 提交
6. 订单页「待审核」页签看到新订单（需求描述里带【健康评估】附言）

**第 2 幕 · 管理员审核（周管理员）**
7. H5 后台登录周管理员 → 订单管理 → 找到这笔待审核订单 → 点「通过」

**第 3 幕 · 互助员接单（李叔叔）**
8. 小程序登录李叔叔 → 自动进入互助员端 → 抢单广场接到这笔单 → 「完成服务」

**第 4 幕 · 确认 + 评价（陈阿姨）**
9. 陈阿姨订单页 → 「待确认」→ 确认完成（时间币自动结算，双方流水可查）
10. 「已完成」→ 去评价 → 点标签（会高亮）→ 提交 → 提示获得 1 时间币奖励

**第 5 幕 · 后台复盘（周管理员）**
11. H5 后台订单管理 → 服务类型筛选「陪诊服务」→ 展示 10 笔演示订单全状态
12. 数据统计页 → 服务类型切「陪诊服务」→ 看陪诊专属趋势图与状态分布

## 七、常见问题

| 问题 | 处理 |
|---|---|
| 手机小程序请求失败 | 手机与电脑不在同一 WiFi；或没勾「不校验合法域名」 |
| 电脑/模拟器也报「网络连接异常」 | 电脑 IP 变了（config.js 里是旧 IP）：重新双击 `启动服务.bat`（会自动更新 IP），或手动改 config.js 的 baseUrl |
| 后端起不来 | 双击 `启动服务.bat` 即可（已在运行会自动跳过）；重启电脑后先开 MySQL（bat 会自动 `net start MySQL80`） |
| H5 后台打不开 | 双击 `启动管理后台.bat`，等 5 秒浏览器自动打开；手动访问 http://localhost:5173 |
| 演示数据想重置 | 管理员演示前可执行 `node scripts/reset-demo-data.js`（全量重置）后，再执行 `node scripts/prepare-peizhen-demo.js`（重建陪诊演示数据） |
| 账号密码错误 | 密码 = 手机号 + `hhL.`（注意区分大小写），验证码 = 123456 |
